# Historical plan documents (not maintained)

This directory holds the documents that led to the current plan:

- `00`–`05`: the original overview, research, "Part 1/Part 2" split and milestone notes;
- `06`–`25`: per-topic analyses (progress, dialogs, theming, nodes/views, property sheet, options,
  output/terminal, debugging, profiling, Java editor intelligence, refactoring, hints, codegen, Javadoc,
  testing, VCS/diff, misc Java features);
- `26`–`34`: earlier plan revisions (roadmap, layer map, beyond-Swing, annotation split, API governance,
  front-end APIs, tiers, retirement, upstream/budget);
- `README.md`: the previous index.

They are the **evidence base** behind [`../PLAN.md`](../PLAN.md): NetBeans class/file references, counts,
formats and licence notes. They are **not** the plan and are not updated; naming, tiers, modules and steps
have changed since they were written. Consult them for research, never for the current design.
